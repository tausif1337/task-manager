The Project

Tausif

What we’re building

Task Manager — add a task, tick it off, delete it. React on the front, Django REST Framework and MySQL on the back.

  • Create a task: title + optional description
  • Toggle complete / incomplete, with a live 3 of 7 complete counter
  • Delete a task
  • REST API over MySQL — six endpoints from one viewset
  • No page reloads — the list updates from React state
  • One services/ module owns every HTTP call
Tausif

The two halves

Browser
  React (Vite dev server, :5173)
    components/  →  App.jsx  →  services/taskApi.js
                                       │  fetch, JSON over HTTP
                                       ▼
  Django (runserver, :8000)
    urls.py → views.py → serializers.py → models.py
                                       │  Django ORM
                                       ▼
  MySQL   task_manager_db . tasks_task

Two servers run at once. The browser talks to Django over HTTP; Django talks to MySQL through the ORM. Neither side imports the other.

Tausif

How one action flows

User submits TaskForm
  → onAddTask({ title, description, is_completed: false })
    → createTask()                POST /api/tasks/
      → DRF serializer validates  → Task.objects.create()
        → 201 Created + JSON      → setTasks([saved, ...tasks])
          → TaskList re-renders    → the new row appears

We build it bottom-up: model → serializer → view → route, then service → state → components.

The REST contract

MethodURLWhat it does
GET/api/tasks/list every task, newest first
POST/api/tasks/create a task, returns 201 + the new row
GET/api/tasks/5/read one task
PUT/api/tasks/5/replace a task (all fields required)
PATCH/api/tasks/5/update some fields — what we use for toggling
DELETE/api/tasks/5/delete a task, returns 204 No Content

The trailing slash is required. DRF’s DefaultRouter builds these URLs. Drop the slash and the two verbs behave very differently — the next slide shows exactly how.

What really happens without the slash

RequestResult
GET /api/tasks301 redirect to /api/tasks/ — harmless.
POST /api/tasks500 RuntimeError — Django refuses to redirect.
RuntimeError: You called this URL via POST, but the URL doesn't end in a
slash and you have APPEND_SLASH set. Django can't redirect to the slash URL
while maintaining POST data. Change your form to point to
127.0.0.1:8000/api/tasks/ (note the trailing slash), or set
APPEND_SLASH=False in your Django settings.

Your POST body is never silently lost. CommonMiddleware raises loudly and names the fix — so when you meet this 500, add the slash and move on.

The API

Tausif

tasks/models.py

from django.db import models


class Task(models.Model):
    title = models.CharField(max_length=200)
    description = models.TextField(blank=True)             # optional
    is_completed = models.BooleanField(default=False)
    created_at = models.DateTimeField(auto_now_add=True)   # stamped once
    updated_at = models.DateTimeField(auto_now=True)       # stamped every save

    class Meta:
        ordering = ["-created_at"]      # newest first, everywhere

    def __str__(self):
        return self.title

blank=True means “may be empty when validating”. auto_now_add fires only on insert, auto_now on every save — both are read-only to clients.

tasks/serializers.py

from rest_framework import serializers

from .models import Task


class TaskSerializer(serializers.ModelSerializer):
    class Meta:
        model = Task
        fields = [
            "id", "title", "description",
            "is_completed", "created_at", "updated_at",
        ]
        read_only_fields = ["id", "created_at", "updated_at"]

A serializer is a translator both ways: model → JSON on the way out, JSON → validated data on the way in. read_only_fields means a client that POSTs an id is politely ignored.

The Service Layer

Tausif

src/api.js — read and create

const API_URL = "http://127.0.0.1:8000/api/tasks/";

export async function getTasks() {
  const response = await fetch(API_URL);
  if (!response.ok) {
    throw new Error("Could not load tasks");   // fetch does NOT throw on 404/500
  }
  return response.json();
}

export async function addTask(task) {
  const response = await fetch(API_URL, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(task),
  });
  if (!response.ok) {
    throw new Error("Could not add task");
  }
  return response.json();
}

One constant holds the whole endpoint — including its trailing slash. Build every other URL from it and you can never forget the slash.

Tausif

src/api.js — update and delete

export async function editTask(id, changes) {
  const response = await fetch(API_URL + id + "/", {     // .../tasks/5/
    method: "PATCH",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(changes),
  });
  if (!response.ok) {
    throw new Error("Could not update task");
  }
  return response.json();
}

export async function removeTask(id) {
  const response = await fetch(API_URL + id + "/", {
    method: "DELETE",
  });
  if (!response.ok) {
    throw new Error("Could not delete task");
  }
  // 204 No Content - there is no body to parse
}
Tausif

Four rules for this file

  • fetch only rejects on network failure. A 400 or a 500 still resolves — you must check response.ok yourself.
  • Throw here, catch in the component. Every function either returns data or throws; no { ok, data, error } objects to unpack.
  • PATCH, not PUT. PUT replaces the row and demands every field — a missing title comes back 400 { "title": ["This field is required."] }. PATCH sends { is_completed: true } and leaves the rest alone.
  • Every URL ends in a slash. A POST to /api/tasks is a 500, not a redirect.
  • The base URL sits in one const — one line to change for deployment.

App.jsx — state design

export default function App() {
  const [tasks, setTasks] = useState([]);     // the server's rows
  const [error, setError] = useState("");     // one message for all calls

  // Derived, not stored: recomputed on every render, never stale.
  const doneTasks = tasks.filter((task) => task.is_completed);
}
<p className="text-sm text-slate-600">
  {doneTasks.length} of {tasks.length} complete
</p>

Derive, don’t duplicate. doneTasks is not state — a second useState for the count would drift out of sync the moment a task is deleted.

Tausif

App.jsx — load once on mount

async function loadTasks() {
  try {
    const tasksFromServer = await getTasks();
    setTasks(tasksFromServer);
  } catch (err) {
    setError(err.message);
  }
}

useEffect(() => {
  loadTasks();
}, []);                        // [] = run once, after the first render

Drop the [] and the effect runs after every render — each fetch sets state, which triggers a render, which fetches again. Infinite loop.

Tausif

App.jsx — add a task

async function handleAdd(newTask) {
  try {
    const savedTask = await addTask(newTask);
    setTasks([savedTask, ...tasks]);
  } catch (err) {
    setError(err.message);
  }
}

Prepend the server’s row, not the object you sent — only the response has id, created_at and updated_at. Newest first matches the model’s ordering, so a refresh shows the same order.

Tausif

App.jsx — toggle

async function handleToggle(task) {
  try {
    const updatedTask = await editTask(task.id, {
      is_completed: !task.is_completed,     // flip it here, send only this
    });
    const newTasks = tasks.map((oldTask) => {
      if (oldTask.id === task.id) {
        return updatedTask;
      }
      return oldTask;
    });
    setTasks(newTasks);
  } catch (err) {
    setError(err.message);
  }
}

map builds a new array, swapping in the row the server sent back. The other rows are passed through untouched — never mutate the array you already have.

Tausif

App.jsx — delete

async function handleDelete(id) {
  try {
    await removeTask(id);
    const newTasks = tasks.filter((task) => task.id !== id);
    setTasks(newTasks);
  } catch (err) {
    setError(err.message);
  }
}

filter keeps every row whose id is not the one you deleted. Delete on the server first, then update state — if the request throws, the row stays on screen and the error shows.

The errors you will hit

  • CORS blocked — corsheaders missing from INSTALLED_APPS, CorsMiddleware not first, or your port not in CORS_ALLOWED_ORIGINS.
  • 500 RuntimeError on POST — you dropped the trailing slash. Django will not redirect a POST; it raises and tells you to add the slash. Use /api/tasks/, never /api/tasks.
  • NotSupportedError — your MySQL or MariaDB is too old for Django 5.2. Check SELECT VERSION(); against slide 21.
  • OperationalError — MySQL isn’t running, the password is wrong, or you never created task_manager_db.
  • 400 Bad Request — title empty or over 200 characters. await response.json() shows exactly which field failed.
  • Nothing renders — key warnings, or state replaced with undefined because a service function returned nothing.
